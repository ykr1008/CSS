CSS specificity is the system browsers use to decide which CSS rule applies when multiple rules target the same element and property. In general, selectors are ranked by specificity: ID selectors have higher specificity than class, attribute, and pseudo-class selectors, while type selectors and pseudo-elements have lower specificity. For example, `#title` overrides `.heading` when both set the same property on the same element. If specificity is equal, the rule that appears later usually wins, assuming the same origin and importance. To keep CSS maintainable, prefer reusable class selectors and avoid unnecessarily increasing specificity or relying on `!important`.
